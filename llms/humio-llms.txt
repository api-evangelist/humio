# Humio

> Humio is a log management and observability platform for ingesting, storing, and searching machine data in real time at scale. Backed by Accel and acquired by CrowdStrike in 2021, it is now delivered as CrowdStrike Falcon LogScale. Developers integrate through a REST API (streaming ingest and search) and a GraphQL API (administration), with official Python, Node.js, Go, and JavaScript client libraries and the humioctl CLI.

## APIs

- [Humio API](https://library.humio.com/stable/docs/api/): REST ingest + search and GraphQL administration API. Base URL https://cloud.humio.com/api/v1. Bearer API/ingest token auth.

## SDKs and tools

- [humiolib (Python)](https://pypi.org/project/humiolib/): Python SDK — `pip install humiolib`.
- [humio (Node.js)](https://www.npmjs.com/package/humio): Node.js logger — `npm install humio`.
- [humio/cli (humioctl)](https://github.com/humio/cli): Go CLI — `go install github.com/humio/cli/cmd/humioctl@latest` or `brew install humioctl`.
- [humio-operator](https://github.com/humio/humio-operator): Kubernetes operator for running Humio.
- [GitHub organization](https://github.com/humio): First-party client libraries, operators, and integrations.
